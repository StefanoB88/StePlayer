# Samsung Seller Office — Test Information

StePlayer is a neutral media player: it ships with no channels or content. To test:
1. Launch the app, tick the confirmation and press "Ho capito e accetto".
2. Choose "Inserisci con il telecomando" → "Lista M3U" and type this URL (Blender Foundation films under Creative Commons
   licenses only):
   https://stefanob88.github.io/steplayerwebsite/demo.m3u
   (Alternatively, "Usa il telefono" receives the list from the StePlayer phone app on the same Wi-Fi.)
3. Press "Salva e connetti", then open "Live" or "Film" and play an item.

Remote keys: RETURN goes back (on Home it exits to Smart Hub), CH+/CH− and numbers change channel, OK long-press or
the red key adds a favourite. No login is needed to test: the optional "Accesso al server" option is only for the
user's own server, and every feature can be tested with the demo M3U list. Network errors are shown on screen and playback retries automatically. The screen saver is disabled only
while a video is playing.
